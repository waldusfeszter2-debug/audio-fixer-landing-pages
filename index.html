Documentation

Frequently Asked Questions

Why is this tool needed?
+
The Dell Latitude 5400 has a documented driver bug where the system fails to detect a headphone jack after the device is disconnected and reconnected — unless a full system restart or manual audio service restart is performed. This occurs due to a timing issue in the Waves MaxxAudio or Realtek driver stack when processing device change events. This utility automates that service restart the moment a detection failure is observed, making the fix invisible and instantaneous.
Does it require Administrator rights?
+
Yes. Restarting the AudioEndpointBuilder and Audiosrv Windows services via PowerShell is a protected system operation that requires standard Administrator-level privileges. The executable ships with a properly configured UAC manifest so the elevation prompt appears cleanly once — not on every detection event.
Is it safe? Can I trust it?
+
Completely. The entire project is open-source on GitHub. You can inspect every line of the Python source code before running anything. The compiled .exe only executes one PowerShell command (Restart-Service) targeting the Windows audio subsystem — nothing else. SHA-256 checksums are published above to verify the integrity of every download.
Does it affect my audio quality or other devices?
+
No. The service restart is a standard Windows operation that takes less than two seconds and does not alter any audio configuration, driver settings, equalizer profiles, or mixer levels. It only forces Windows to re-enumerate audio endpoint devices — the same thing that happens automatically at boot. Bluetooth audio and speakers are not affected.
Does it work on other Dell models?
+
It was built and tested specifically on the Dell Latitude 5400. However, the same driver bug has been reported on several other Dell Latitude and Vostro models that use the Waves MaxxAudio or Realtek driver stack (e.g., Latitude 5401, 5410, 5411). It is likely to work on these models as well, but they are not officially tested. Community reports are welcome via GitHub Issues.
How do I uninstall or disable it?
+
Right-click the system tray icon and select Disable Autostart to remove it from Windows startup, then simply close the application. To fully remove it, delete the .exe file — no uninstaller needed, no registry entries remain, no services are installed.
